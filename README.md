# suiheisen
This is Suiheisen, a game meant to be paired with my own custom macropad (SuiheisenPad) that features four keys. You're a Korean salaryman and you escape your chaebol office building to just run and chase the horizon. You don't know where your legs are taking you, but you don't care as long as it's far away from your dreaded cubicle.

## Controls
- z -> dodge left
- x -> OK/enter
- c  -> duck
- v -> right

## How it works
- Godot Engine
- Main sprite is a CharacterBody3D with a plane mesh with billboarding so it looks 2D
- Blender used for 3D art like background buildings
- Aseprite used for 2D art like start screen, end screen, character sprite/animations, and sky background
- Dodging works by changing the player's CollisionShape3D
